# Reproducing it

The public repository contains the method, the figures and a synthetic estimator. It contains **no
market data**. You can run everything in about a minute, with Python 3 and nothing else.

## Clone and build

```bash
git clone https://github.com/Chanta007/commodity-factor-model.git
cd commodity-factor-model
make build
```

`make build` runs four things:

1. **`make figures`**: regenerates the eight SVGs from the aggregate numbers.
2. **`make check`**: fails on a data file, a file over 2 MB, a missing figure, a broken link, or a
   figure that is not reproducible.
3. **`make test`**: runs the unit tests, including the synthetic estimator.
4. **`make demo`**: estimates a known coefficient from synthetic data.

## Expected demo output

```text
synthetic demonstration, no market data
true beta      0.1700
estimated beta 0.1684
HAC t          41.09
observations   520
R2             0.769
```

The synthetic data is generated by `scripts/estimate.py` with a fixed seed. The estimator is not
told the coefficient; it recovers it from the panel. The HAC t is high because the synthetic noise
is simple and the sample is 520 weeks. **The demo is not the market result.** It shows that the
estimator, the design matrix and the standard errors work.

## Run only the demonstration

```bash
python3 scripts/estimate.py --demo
python3 scripts/estimate.py --demo --beta 0.03 --seed 11
python3 scripts/estimate.py --demo --json
```

The script refuses to run without `--demo`; it has no path to market data.

## What is private and why

The private research repository holds the EIA and FRED series, the vendor curves, the manifest and
the point-in-time store. Those bytes are licensed. The public repository holds the aggregate
results, the method and the figures. See [Data and licences](data-and-licences.md).

## Check the boundaries

```bash
python3 tests/check_public.py
```

It fails if a CSV, Excel, JSONL, Parquet, ZIP, database or HDF5 file appears, if any file exceeds
2 MB, if a figure is missing, if a README section is missing, or if a relative link does not
resolve. The public/private boundary is a test, not a promise.
