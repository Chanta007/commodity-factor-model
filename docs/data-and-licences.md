# Data and licences

This repository is a **public explanation**, not a data distribution. It contains no market data.

## What is not here

- No price series.
- No inventory series.
- No vendor files.
- No point-in-time store.
- No retrieval receipts that name a licensed value.

The figures are aggregate summaries generated from estimated coefficients and test statistics.
They contain no observation-level data.

## What the private research uses

| Source | Use | Why it is not published here |
|---|---|---|
| **EIA** | Weekly stocks, production and the STEO | Public domain, but the repository publishes only the aggregate results, not the series |
| **FRED** | Rates, industrial production, the dollar | FRED's terms bar archiving and redistribution without written consent; the operator's approval covers the private research, not this public repository |
| **Databento** | Live CME and ICE curves | Licensed; redistribution is not permitted |
| **ICE** | Futures settlements and the report data | Licensed; redistribution is not permitted |

The private research repository keeps the raw bytes in a git-ignored store, records one manifest
row per retrieval, and publishes only derived figures and provenance. This repository takes the
next step: it publishes the aggregate findings and the method, and none of the bytes.

## What a reader can check

- Every figure is generated by [`scripts/make_figures.py`](../scripts/make_figures.py) from the
  aggregate numbers in the same file. Regenerating it produces byte-identical SVGs.
- Every number in the prose also appears in the figure or the table.
- [`tests/check_public.py`](../tests/check_public.py) fails if a data file is added, if a figure is
  missing, or if a README link does not resolve.

## A note on derived figures

A chart of aggregate coefficients is a derived work. A chart of the underlying weekly
observations is closer to the data itself. This repository deliberately uses the former. The
scatter plots of the private research are not published here for that reason.

If you need the underlying series, obtain them from the original source under your own licence.
